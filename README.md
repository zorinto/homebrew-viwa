# zorinto/homebrew-viwa

Homebrew tap for viwa: read, reply to and manage WhatsApp Desktop chats from the Mac terminal, through the official WhatsApp app.

```sh
brew install zorinto/viwa/viwa
viwa doctor
```

The formula installs the same prebuilt Apple silicon binary as the npm package [@zorinto/viwa](https://www.npmjs.com/package/@zorinto/viwa), whose README is the full guide. macOS on Apple silicon only.

viwa was called chinwag until version 0.5.0. The old `chinwag` formula stays here at 0.4.4 and gets no further updates.
